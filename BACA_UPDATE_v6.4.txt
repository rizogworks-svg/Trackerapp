PERBAIKAN INPUT NOMINAL TRACKERS v6.4

Paket ini adalah PATCH untuk aplikasi Trackers yang sudah ada, bukan instalasi baru.
Tidak berisi assets/js/config.js, jadi URL dan key Supabase Anda tidak tertimpa.

1. Simpan semua form dan unduh backup data dari aplikasi.
2. Ekstrak ZIP ini ke folder sementara.
3. Salin seluruh ISI hasil ekstrak ke folder aplikasi lama yang berisi index.html.
   Pilih Replace/Timpa file. Jangan hapus folder aplikasi lama.
   Jika melalui GitHub, upload isi patch ke lokasi index.html yang sama dan tunggu deployment selesai.
4. Simpan dan tutup tab Trackers lain.
5. Buka UPDATE_TRACKERS.html melalui alamat server aplikasi yang sama.
   Contoh: jika aplikasi http://localhost:8000/ maka buka
   http://localhost:8000/UPDATE_TRACKERS.html
   Jika aplikasi https://nama.github.io/repo/ maka buka
   https://nama.github.io/repo/UPDATE_TRACKERS.html
   Ganti contoh alamat sesuai alamat aplikasi Anda. Jangan klik HTML sebagai file lokal.
6. Klik Aktifkan versi 6.4. Setelah berhasil, klik Buka Trackers.
7. Buka Harga & Pembayaran. Pastikan muncul tulisan Input nominal v6.4.
   Hapus nilai percobaan lama, ketik 3333333333. Harus tampil 3.333.333.333.
   Simpan dan buka lagi untuk mengecek nilainya.

Jika label v6.4 belum muncul, file aplikasi yang berjalan belum menggunakan revisi ini.
Periksa lokasi folder/server atau deployment Anda. Tidak perlu mengulang SQL,
logout, atau menghapus data situs/browser.

Perbaikan: penanganan titik ribuan ketika mengetik pada Harga SOW Client,
Addwork, pembayaran Client, dan Harga Satuan PKBON. Cache sekarang mencocokkan
versi URL secara tepat, dan tersedia pembaruan manual dengan pemeriksaan versi.
Tanggal pekerjaan dan lebar kolom PKBON dari revisi sebelumnya tetap disertakan.

Nominal yang sebelumnya sudah tersimpan salah tidak diubah otomatis.
Pengujian menggunakan simulasi DOM dan service worker; belum diuji pada browser
atau Supabase produksi milik Anda.
